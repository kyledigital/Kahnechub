## Art direction and scope

Use the existing cream, violet, mint and gold system. The guide is a calm conversational panel opened intentionally from inline buttons. No automatic popup, floating overlay over page content, fake typing, invented online status or new decorative animation. Keep selected states immediate and motion optional. Use native labelled radio groups and a native modal dialog with visible Close, Escape, keyboard containment and focus return. Keep direct contact available throughout.

Answers live in page memory only. The guide introduces no storage, answer analytics, external AI calls or automatic messages. Opening the WhatsApp URL shares the editable draft with WhatsApp; the user still chooses whether to send. Empty drafts cannot open, and long text is bounded and safely encoded. Reopening preserves progress; restart clears it. Editing answers preserves a manually edited draft until the visitor explicitly replaces it.

Reference principles supplied by parent research: clear new-build/review distinction, real need/contribution evidence, a guided planner alongside direct contact and visible solo-expert scope. Reference sites were not copied, and their prices or delivery promises are not adopted. Technical guidance: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ and https://www.w3.org/WAI/tutorials/forms/multi-page/. WhatsApp click-to-chat: https://faq.whatsapp.com/5913398998672934.

Browser limits: the in-app Browser and agent-browser CLI are unavailable in this executor. Current-run captures use installed Chrome through Playwright. The Product Design Python preflight was attempted; Python is unavailable, and no saved context was found through the available environment. The supplied code, current screenshots and approved direction provide the visual grounding.
